# 多语言（i18n）

首期支持 **`zh-CN`（默认）+ `en`**，语言列表集中在 `@be-water/shared` 的 `APP_LOCALES`，可扩展。

## 优先级

与主题 / 布局同构：

1. 用户本地选择（`localStorage: app-locale`）— 侧栏 `LocaleToggle` / 用户菜单
2. 租户默认（`TenantSetting[appearance].locale`）— 平台「租户 → 外观」
3. 平台默认（`AppSetting[platform_settings].default_locale`）— 平台设置
4. 代码兜底 `zh-CN`

公开配置 `GET /api/public/config` 下发 `default_locale`，供登录页在未进租户壳时使用。

## 前端

- 库：`i18next` + `react-i18next`
- 初始化：`main.tsx` 在 React 首屏前 `readStoredAppLocale()` + `setupI18n`；`LocaleProvider`（包在 `AuthProvider` 内）渲染期再同步
- 持久化：`localStorage: app-locale`（用户选择）/ `app-locale-default`（缓存的服务端默认）；`index.html` 内联脚本同步 `document.documentElement.lang`
- 文案：`packages/client-kit/src/i18n/locales/{zh-CN,en}/<ns>.json`
- 已注册 namespace：`common`、`shell`、`user`、`notes`、`todos`、`billing`、`rbac`、`dashboard`、`notification`、`audit`、`background-job`、`error-log`、`slow-query`、`platform`、`marketing`
- 共享字典客户端翻译：审计 action（`audit:actions.*`）、错误级别（`error-log:levels.*`）、套餐/配额（`platform:plans.*` / `platform:limits.*`）；服务端 shared 中文标签保留作默认与落库
- 新模块：补 JSON → 在 `setup.ts` 的 `I18N_NAMESPACES` / `resources` 注册 → 组件内 `useTranslation('<ns>')`
- 导航标签可用 `namespace:key`，由 `translateAppNavSections` / `resolveNavLabel` 在渲染时翻译
- API 客户端自动带 `Accept-Language: <当前 UI 语言>`

## 官网 URL 与静态页

- 无前缀路径（`/`、`/pricing`、`/docs/...`）= 默认语言 `zh-CN` 的主入口
- 前缀路径 `/{locale}/...`（如 `/en/pricing`、`/zh-CN/pricing`）= 带 locale code 的静态页；预渲染与 sitemap 会展开全部 locale
- 官网语言切换会改写 URL，并写入 `app-locale`；无前缀访问时若本地已选非默认语言，客户端 replace 到对应前缀路径
- `/zh-CN/...` 的 canonical 指向无前缀主入口，避免重复收录

## 后端

- 错误响应在 `onSend` 边缘按 `Accept-Language` 翻译 `{ error }`
- 目录：`packages/server-kernel/src/lib/i18n/messages-en.ts`（key = 中文原文）
- 业务代码继续抛中文（默认语言）；新增用户可见文案时同步补英文条目
- 日志 / 审计 details 保持中文原文，不翻译

## 扩展语言

1. `APP_LOCALES` 追加一项
2. 补 `client-kit`（及模块）locale JSON
3. 补 `messages-en.ts` 同类目录（如 `messages-ja.ts`）并在 `translateApiMessage` 挂载
