每个租户拥有一个营销站点，由页面、主题、页头页脚组成。本篇介绍如何从起步模板开始搭建你的站点。

## 起步模板

新站点从起步模板（Starter）开始。模板 = 主题包 + 页面组合，开箱即用：

| 模板       | 适用场景             | 包含页面                       |
| ---------- | -------------------- | ------------------------------ |
| `default`  | 通用起步             | 首页                           |
| `product`  | 产品官网             | 首页 + 定价 + 关于 + 联系     |
| `landing`  | 单页落地             | 首页 + 联系                    |

在站点管理页可以一键应用模板。应用模板会覆盖现有页面内容，但不会删除你自建的页面。

## 主题

主题是一组设计 token（颜色、字体、间距），决定站点的视觉基调：

- 在站点设置里切换主题包
- 主题 token 可被站点级覆盖（如自定义主色）
- Logo 是品牌资产，独立于主题单独配置

## 页头与页脚

页头（Header）与页脚（Footer）是站点级 section，所有页面共用：

- 页头：可配置 logo、站名、导航、粘性、布局
- 页脚：可配置 logo、简介、版权、链接组

> 模板**不**配页头按钮。需要 CTA（如「免费开始」）的，在页头设置里自己加一条。

### 导航链接

选中页头后，右侧的「导航链接」就是访客看到的那一排——条目在这里直接添加、排序、
删除。点「添加」可选预设：

| 来源           | 用来做什么                                       |
| -------------- | ------------------------------------------------ |
| 自定义链接     | 一条你自己填的链接，可再挂一层子菜单             |
| 全部一级页面   | 自动列出所有已发布的一级页面，新建页面自动进导航 |
| 文档库         | 整个文档库，按分类分组（父项链到 `/docs`）       |
| 某个文档分类   | 指定分类下的全部已发布文档                       |

后三种是**规则**，展开成哪些链接由内容决定——旁边会写着「会显示：…」。写着「现在
展开不出任何内容」时这一条不会出现在导航里。

建站默认是「全部一级页面」+「文档库」：有已发布文档后页头自动出现「文档」入口；
还没写文档时那条不渲染。文档列表页本身不进「一级页面」目录。

页脚每一列有自己的链接列表。要和页头一样时，点「从页头复制」（快照，之后两边各自改）。

## 站名与标语

站名与标语是站点的身份标识，显示在页头与 SEO 元信息里。开站第一件事就是改掉模板的占位文案。

## 多语言

站点支持多语言：

- 主语言（`default_locale`）是文档库与页面内容的基准语言
- 可启用额外语言，为页面提供翻译
- 访客按浏览器语言或 URL 前缀切换

文档库 v1 只编辑主语言，非主语言整库回落主语言展示。

## 站点发布

站点有 `published` 开关：

- 关闭时访客看到的是占位页
- 开启后访客能看到已发布的页面与文档

页面与文档各自还有独立的 draft/live 状态——站点发布只是总开关，具体内容上线要逐个发布。
