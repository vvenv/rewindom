每个站点有一个营销站点，由页面、主题、页头页脚组成。这一篇讲从起步模板到站点上线的
那条主路径。

## 起步模板

新站点从起步模板开始。一个模板 = 一个主题包 + 一组页面：

| 模板     | 适用场景 | 建出哪些页面                  |
| -------- | -------- | ----------------------------- |
| 默认营销站 | 通用起步 | 首页                          |
| 产品官网 | 产品官网 | 首页 + 定价 + 关于 + 联系     |
| 单页落地 | 单页落地 | 首页 + 联系（留白更大的主题） |

在站点管理页一键应用。应用模板会**覆盖同名页面的内容**，但不会删掉你自建的页面。

> 「默认营销站」只建一个首页，是刻意的：起步模板铺出来的每一页，往往第一件事就是删
> 掉它。要定价页、关于页就在页面预设里加一页，成本比删干净低得多。

## 主题

主题是一组设计 token（颜色、字体、间距、圆角），决定站点的视觉基调：

- 在站点设置里切换主题包
- 单个 token 可以站点级覆盖（比如只换主色）
- Logo 是品牌资产，独立于主题单独配置

## 页头与页脚

页头与页脚是**站点级**的段，所有页面共用一份：

- 页头：默认是「品牌 + 导航 + 语言切换 + 明暗切换」四块，可增删可排序
- 页脚：默认只有一行版权；简介与链接组按需自己加

语言与明暗两块默认就在，是因为它们**不适用时压根渲染不出东西**：站点只有一种语言时
语言切换器不显示，等你发布了第一版译文它自己就出现了。不需要的话在左树上点一下删掉。

在站点管理页点右上角的**「页头页脚」**进编辑器，不必打开某一页的 Theme Editor。
保存草稿与发布互不影响页面正文。

> 模板**不**预置页头按钮。需要「免费开始」这类 CTA 的，在页头设置里自己加一条——
> 预置一个指向未开通功能的按钮，比没有按钮更糟。

### 导航链接

选中页头后，右侧的「导航链接」就是访客看到的那一排。点「添加」可选四种来源：

| 来源         | 展开成什么                                       |
| ------------ | ------------------------------------------------ |
| 自定义链接   | 一条你自己填的链接，可再挂一层子菜单             |
| 全部一级页面 | 所有已发布的一级页面，新建页面自动进导航         |
| 文档库       | 整个文档库，按分类分组（父项链到 `/docs`）       |
| 某个文档分类 | 指定分类下的全部已发布文档                       |

后三种是**规则**而不是固定条目：展开成哪些链接由内容决定，编辑器里会写着「会显示：
…」。写着「现在展开不出任何内容」时，这一条在前台不渲染——不会留下一个点进去是空
列表的入口。

建站默认只配「全部一级页面」——发布页面后导航自动更新。文档库入口要自己加；加了文档
动态项之后，写了第一篇文档才会出现对应入口。

页脚的每一列有自己的链接列表。想和页头一致时点「从页头复制」——复制的是快照，之后
两边各改各的。

## 站名与标语

站名与标语显示在页头和 SEO 元信息里，支持按语言分别填写。开站第一件事就是把模板的占位文案改掉。

## 多语言

站点支持多语言，**主语言的 URL 不带前缀**（它是 SEO 主入口），其余语言走
`/{locale}/…`。页面与文档都是**按语言分行存**的：同一路径每种语言各一份，它们靠路径
自动成为一组译文，语言切换器和 hreflang 据此生成。

某种语言一篇文档都没有时，文档库整库回落主语言展示——不 404。

## 发布

站点有一个总开关：关着时访客看到占位页，开了才能看到内容。

页面和文档各自还有独立的草稿 / 已发布状态。**总开关只是总开关**，具体内容上线仍要
逐个发布。
