# 会员系统

会员（site-member）是租户站点面向访客的账户体系。与租户内部用户（工作台管理员）不同，会员是站点访客身份。

## 会员 vs 用户

|          | 会员（Member）          | 用户（User）              |
| -------- | ----------------------- | ------------------------- |
| 身份     | 站点访客                | 租户管理员                |
| 入口     | `/member/*`             | `/app/*`                  |
| 登录     | 会员登录页              | 工作台登录                |
| 权限     | 访问会员专属内容        | RBAC 角色权限             |
| 管理位置 | 站点管理 → 站点会员     | 管理后台 → 用户           |

会员是按租户开通的能力，默认关闭。开通后页头会出现登录/账户入口。

## 会员登录

会员通过 `/member/login` 登录，凭据由租户配置（邮箱密码或 OAuth）。登录后 cookie 标识会员身份，可访问会员专属内容。

## 会员专属内容

通过 `member-gate` section 实现内容门控：

- 未登录访客看到 gating 提示（如「登录后查看」）
- 登录会员看到完整内容
- 可配置哪些 section 需要会员身份

## 会员管理

在站点管理 → 站点会员页面：

- 查看会员列表
- 启用/停用会员
- 查看会员活动

## 会员账户页

会员登录后访问 `/member/account`：

- 查看与修改个人信息
- 修改密码
- 查看会员状态

## OAuth 登录

租户可配置 OAuth 登录（如微信、GitHub），需要在平台控制台配置 OAuth 应用凭据。会员通过 OAuth 登录后会绑定到对应会员账户。

## 何时启用会员

适合需要内容门控的场景：

- 知识库 / 课程站点
- 仅会员可见的资源下载
- 收集访客信息后开放内容

如果站点只是纯展示（落地页、官网），不需要会员系统，保持关闭即可——否则页头会挂一个点进去没意义的登录入口。
