# 文档库管理

每个租户有一个文档库，对外暴露在 `/docs`（索引）与 `/docs/:slug`（详情）。本篇介绍如何管理文档内容。

## 文档结构

一篇文档就是「标题 + Markdown 正文 + 分类」，不进页面版式体系：

| 字段         | 说明                         |
| ------------ | ---------------------------- |
| `slug`       | URL 路径段（`/docs/<slug>`） |
| `title`      | 标题                         |
| `description`| 摘要（进 SEO 与列表）        |
| `body_md`    | Markdown 正文                |
| `category`   | 分类（用于索引分组）         |
| `sort_order` | 排序权重                     |

## 草稿与发布

与页面同口径：

- 编辑器改的是**草稿**（`_draft` 列）
- 发布后草稿复制到**线上**，访客才能看到
- `status=draft` 的文档不出现在 `/docs` 索引里

工作流：编辑草稿 → 预览确认 → 点「发布」上线。草稿改坏了可以「撤销」，把线上内容回灌进草稿。

## 创建与编辑

在站点管理 → 文档库页面：

1. 点右下角悬浮按钮新建文档
2. 填写 slug、标题、分类、正文
3. 保存（写草稿）
4. 在列表行操作菜单里点「发布」

编辑器支持分屏预览：左侧写 Markdown，右侧实时看到渲染效果，并带工具栏快速插入格式。

## Slug 规则

- 单段，字母数字开头结尾，中间可含连字符
- 最长 63 字符
- 全小写
- 示例：`quickstart`、`api-reference`、`faq`

slug 一经创建不可修改（避免外链失效）。

## 导入与导出

支持 `.md` 文件批量导入导出：

- **导入**：上传 `.md` 文件，文件名即 slug，frontmatter 提供标题/描述/分类。同 slug 已存在则覆盖草稿。
- **导出**：单篇或全部导出为带 frontmatter 的 `.md` 文件。

frontmatter 格式：

```markdown
---
title: 文档标题
description: 文档简述
category: 分类名
---

正文内容...
```

## 分类与排序

- 文档按 `category` 分组展示在索引页
- 未填分类的归到「其它」，恒排最后
- 同分类内按 `sort_order` 升序，再按标题排序

## 多语言

文档库 v1 只编辑站点主语言。非主语言请求时**整库回落**主语言展示——请求语言一篇都没有时，不 404 而是展示主语言内容。

## 与平台文档的区别

|          | 平台文档             | 租户文档库           |
| -------- | -------------------- | -------------------- |
| 存储     | 代码仓库 `.md` 文件  | 数据库表             |
| 版本     | 跟代码版本走         | 运行时编辑           |
| 可编辑   | 租户不可编辑正文     | 租户自管             |
| 引用方式 | `doc-source` section | `/docs` 路由         |
| 用途     | 官方指南（如本篇）   | 租户自己的帮助文档   |
