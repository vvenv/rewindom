每个站点有一个营销站点，由页面、主题、页头页脚组成。新组织创建时会自动铺好默认首页与
页头页脚。之后的主路径是：点页面行 → 改区块 → 发布。

## 进编辑器

站点管理页卡头两颗按钮各干一件事；进编辑器靠下方页面行：

| 按钮 / 入口 | 打开什么                                       |
| ----------- | ---------------------------------------------- |
| 查看官网    | 新窗口看访客看到的站                           |
| 站点设置    | Sheet：站名、语言、发布、重定向                |
| 页面行      | 官网编辑器（该页 + 页头页脚 / 主题）           |

系统初始化的模板页（首页、文档版式等）**不可删除**，只可重设为最新版式。自建页面仍可删。

编辑器里：

- **区块** — 同一棵树里改页面元信息、页头、页面区块、页脚
- **主题设置** — 主题包、配色、字体、间距、品牌资产

## 主题设置

主题是一组设计 token（颜色、字体、间距、圆角），决定站点的视觉基调：

- 在编辑器的「主题设置」里切换主题包
- 单个 token 可以站点级覆盖（比如只换主色）
- Logo 是品牌资产，独立于主题包 token 单独配置

要把模板页结构拉回最新内置版式，用页面行上的**重设版式**；要把某个主题包的默认值
重新套上，用主题设置里该包的**重设为最新**。

## 页头与页脚

页头与页脚是**站点级**的段，所有页面共用一份，而且是**同一套东西**：同一批区块、同样
的摆法。区别只有页头能吸顶、页脚能设与正文的距离。

默认页头是「Logo + 站名 + 一级页面导航 + 语言 + 深色模式」，默认页脚是一行版权。

> 语言与深色模式默认就在，是因为它们**不适用时压根渲染不出东西**：站点只有一种语言时
> 语言切换器不显示，等你发布了第一版译文它自己就出现了。不需要的话在左树上点一下删掉。
> 按钮、文档搜索、会员入口默认**不**预置——预置一个指向未开通功能的按钮，比没有更糟。

### 摆在哪里，由区块自己说了算

选中任一个区块，「位置」里有三项：

| 设置     | 说明                                                          |
| -------- | ------------------------------------------------------------- |
| 所在行   | 页头 / 页脚最多三行，空行不显示                               |
| 行内对齐 | 靠左 / 居中 / 靠右                                            |
| 窄屏     | 留在外面 / 收进菜单 / 不显示                                  |

常见排法都是这三项拼出来的，没有「版式」下拉：

- **导航居中**：把导航块的对齐改成「居中」
- **页头带公告条**：把一个文字块放到第一行，品牌与导航放第二行
- **典型的多列页脚**：第一行放品牌 + 几个「竖列」导航块，第二行放版权（靠左）与语言、
  深色模式（靠右）
- **底栏的隐私 / 条款 / 备案号**：第二行加一个「横排」导航块，靠右

### 区块清单

| 区块       | 用途                                                        |
| ---------- | ----------------------------------------------------------- |
| 品牌       | Logo、站名、一句话简介                                      |
| 导航       | 一组链接。**横排**适合页头与底栏，**竖列**适合页脚的链接列  |
| 文字       | 版权、备案说明、公告                                        |
| 按钮       | CTA                                                         |
| 文档搜索   | 站里有已发布文档时才显示                                    |
| 语言       | 本页有其他语言译文时才显示                                  |
| 深色模式   | 明暗切换                                                    |
| 账户入口   | 会员登录 / 账户菜单（需开通会员）                           |

八种在页头页脚都能加——语言收进页脚、页头放一句公告文字，都是一下的事。

### 文字里的占位符

文字区块支持两个占位符：`{year}` 是当前年份，`{site}` 是站点名。默认的
`© {year} {site}` 因此跨年会自己变、改了站名也跟着变。想写「© 2020–{year} Acme, Inc.」
直接改就行。

### 手机上

设成「收进菜单」的区块会折进右上角的汉堡菜单，桌面上照常显示。品牌、深色模式这类小
控件适合「留在外面」；文档搜索框这类窄屏放不下的，设成「不显示」。

### 导航链接

选中导航区块，「链接」就是访客看到的那一组。点「添加」可选四种来源：

| 来源         | 展开成什么                                       |
| ------------ | ------------------------------------------------ |
| 自定义链接   | 一条你自己填的链接，可再挂一层子菜单             |
| 全部一级页面 | 所有已发布的一级页面，新建页面自动进导航         |
| 文档库       | 整个文档库，按分类分组（父项链到 `/docs`）       |
| 某个文档分类 | 指定分类下的全部已发布文档                       |

后三种是**规则**而不是固定条目：展开成哪些链接由内容决定，编辑器里会写着「会显示：
…」。写着「现在展开不出任何内容」时，这一条在前台不渲染——不会留下一个点进去是空
列表的入口。

建站默认只配「全部一级页面」——发布页面后导航自动更新。页脚的导航块想和页头一致时点
「从页头复制」，复制的是快照，之后两边各改各的。

### 留白与分隔线

页头 / 页脚设置里能调上下内边距、行内间距，以及朝着正文那一侧的分隔线（页头在下、
页脚在上）。把页脚换成深色底时，通常要把分隔线关掉。

要按份额分栏、每栏装一段正文或一个订阅表单的页脚，在页脚组里**添加「分栏」段**——和
页面上用的是同一个区块，拖分栏点调列宽。页脚本体不重复提供一套只在这里生效的列宽设置。

> 社交平台图标（GitHub / X / 微信…）暂时没有专门的区块。要放的话，用「分栏」加一段
> 正文，在里面写带图片的链接。

## 站名与标语

站名与标语显示在页头和 SEO 元信息里，支持按语言分别填写。开站第一件事就是把初始化
占位文案改掉。

## 多语言

站点支持多语言，**主语言的 URL 不带前缀**（它是 SEO 主入口），其余语言走
`/{locale}/…`。页面与文档都是**按语言分行存**的：同一路径每种语言各一份，它们靠路径
自动成为一组译文，语言切换器和 hreflang 据此生成。

某语言下没有任何文档时，文档库会回落到主语言，而不是 404。

## 发布

站点有一个总开关：关掉后访客只看到占位页。

页面与文档各自还有草稿 / 已发布状态。**总开关只是总开关**——具体内容仍要单独发布。
