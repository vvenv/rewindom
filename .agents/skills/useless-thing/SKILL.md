# 造一件无用之物

模块：`modules/useless/`　约定：`modules/useless/MODULE.md`　把关：`server/seed-embeds.test.ts`

「无用」是反话。它反的是**凡事先问有什么用**。所以一条东西光是漂亮不够，
光是把一个道理讲清楚更不够——讲清楚是在给那套秩序做注解，不是在拒绝它。

## 第 0 步：把关键词变成一个拒绝，不是变成一个演示

这一步做错，后面全白做。拿到关键词先写两句话：

```
机制：___ 会导致 ___                    ← 谁都写得出，没用
拒绝：这条东西不给读者 ___，因为 ___     ← 这才是要做的东西
```

以「乌合之众」为例：

- ❌ 机制版：一群点互相跟随，个体判断被淹没。**这是 boids，仓库里已经有 `群` 了。**
- ❌ 论证版：单独决策 vs 群体决策的正确率对比，底下两条杠。**这是社会心理学课件。**
- ✅ 拒绝版：你有一个只对你自己生效的开关。人越多它越迟钝，
  而**没有"退出人群"这个按钮**——不是我没做，是那件事本身没有退出键。

### 先查重（省下一整轮返工）

```bash
pnpm --filter @rewindom/useless exec tsx scripts/_claims.ts <标题>...   # 打印各条的说法
grep -n 'title: "' modules/useless/server/seed-embeds/{auto,tap}.ts
```

**机制重复比标题重复更常见，而且测试查不出来。**
实例：`蒸发冷却`（最温和的先走、剩下的一个字没改、中心自己移了）和
`柠檬市场`（东西比价钱好的先退出、剩下的平均更差）是同一套东西换了层皮。

## 两道关

抄自 `seed-embeds.test.ts` 底部那段注释，那里是真源。

**一、翻到这一天，你会想动手，或者愿意让它开着。**
挡在外面的三类：一句话的笑话（懂了就完）、循环播放的花纹（第二眼没有新东西）、
把输入映射成一个标量的演示（它证明的是「我读得到你」，不是一件事）。

**二、机制自己要说出一件事，而且不许靠旁白说。** 两条判据缺一不可：

| 判据 | 不过关的样子 |
| --- | --- |
| 换个名字放进 GPU 厂商的发布会背景毫无违和 | 漂亮的物理演示是实用主义的战利品 |
| 换个名字放进行为经济学课件、增长团队入职材料里毫无违和 | **论证不等于立场** |

第二条最容易漏。漂移是有原因的：`probe-useless.ts` 只证得了能压成一句可转述命题的
东西，于是「可验证」会悄悄变成「可教学」。**核对台会挑食，别让它替你定标准。**

## 拒绝的六种形状——换的是这个，不是手势

做到第四第五条时最大的风险，是十五条变成十五个带记分板的小游戏。
判断有没有重样，看的是**拒绝**这一列，不是**手势**那一列。

| 形状 | 已有的 | 手势 |
| --- | --- | --- |
| 花掉自己 | `最后一个键` 用一次少一个、`一次` 松手当场没 | 按 / 按住 |
| 不给第三条路 | `柠檬市场` 卖也亏不卖也亏、`诱因` 只有一个杠杆而它就是病因 | 点一下 / 按住 |
| 不给你知道 | `赢家诅咒` 不押就不揭真值、`回归` 不替你画对照线、`幸存者` 可辨认的时刻早过去了 | 拖线 / 划带 / 挑一个 |
| 不给加速、不给分享、不给看第二遍 | `洞穴` | — |
| 它自己的成功把它毁掉 | `河` 刻到没地形、`晶` 粗化到没晶界、`黏菌` 优化到没冗余 | 无 |
| 把你的用力反过来 | `一口气` 憋越久呼得越慢、`搜索` 你越用它剩下的越少 | 按住 / 指针 |

**记忆只记代价，不记进度**（`MEM` 顶部写死了这条）：跳过的次数、多付的、照没的。
存住的东西下次回来只会让它更难玩，不会让它更好玩。

## 骨架

`server/seed-embeds/shell.ts` 提供：`play(css, body, js)`、`BOX`、`FIT`、`MEM`、
`stageCss(cls, extra)`、`stageBody(cls)`。`tap.ts` 放要动手的，`auto.ts` 放自己在长的。

```ts
{
  title: "两个字最好",
  html: play(
    stageCss("ut-xxx", ";touch-action:none;cursor:crosshair"),
    stageBody("ut-xxx"),
    MEM +            // 要跨访问记代价才加
      FIT +          // 画布 + dpr + ResizeObserver + INK()
      // 说法写在这里。写给下一个改它的人看，不进页面
      "var ...;" +   // ① 所有顶层 var
      "function ..." // ② 所有函数
      "alloc();" +   // ③ 裸调用只能排在①之后
      "function tick(){...requestAnimationFrame(tick);}tick();" +
      "CV.addEventListener('pointerdown',function(e){...;e.preventDefault();});",
  ),
}
```

**作用域三条**（没有 iframe，越界会改掉整个官网）：CSS 选择器一律收在
`.useless-thing` 里；事件绑在 `CV` 上，**不许**碰 `document` / `window`；不用 id 选择器。

## 关键坑

前四条是仓库里栽过的，测试已经逐条把关，改前先读 `seed-embeds.test.ts` 的注释。

| 坑 | 后果 |
| --- | --- |
| 拼接多打一个 `+`（`"a" + +"b"`） | 整段求成 `NaN` 被吞，**解析得过**，页面却是空的 |
| 重新声明 `FIT` 占用的 `CV/G/W/H/onfit/INK/fit/at` | 提升覆盖，画布从没被定过尺寸，同步阶段抛错，`try/catch` 抓不到 |
| 裸调用排在它要读的顶层 `var` 前面 | 同上，静默一个像素都不画 |
| 写成 `MEM.num(...)` | 运行时那个对象叫 `M`，同步阶段 ReferenceError |

下面五条是**调参**踩出来的，测试查不出来，只有探针查得出：

| 坑 | 实例 |
| --- | --- |
| 把累积量按总量归一 | `赢家诅咒` 的账：一条记录就占满整条带子，第二条起再也看不出在涨。累积就用绝对刻度，溢出靠裁剪 |
| 过程快到看不见 | `柠檬市场` 原本三十帧见底。要给人看「一层层塌」，退出就得是**陆续**的（每步一个小概率），不能一刀切 |
| 把系统推到吸收态 | `诱因` 长按会把种群抓绝，绝种之后什么都长不回来。凡是能到零的量，都要么加密度依赖（越少越难抓），要么留一条补充通道 |
| 稳态写成了临界 | `诱因` 的野生繁殖原本「和自然死正好打平」，等于只要有一点养殖就无限涨、松手再也回不来。稳态得是稳态 |
| 环境项盖过读者 | `搜索` 的自动查询原本 1200 帧就抹掉 95%，那盏灯就不是原因了。读者的动作要比环境快一个量级 |

还有一条不是坑是纪律：**「跑到尽头」不等于「跑完之后干晾着」。**
`烟` 停供后静置 3200 帧，可卷须 1400 帧就散尽了——每两分钟给人看半分钟纯黑。
给结局留的帧数要量出来，别拍。

## 核对流程

四步都要跑，各查各的，互相替代不了。

```bash
# ① 作用域与拼接。改完必跑
pnpm --filter @rewindom/useless test

# ② 说的和做的是不是一回事。收东西前必跑，光看着像是不够的
pnpm --filter @rewindom/useless exec tsx scripts/probe-useless.ts <标题> <探针文件> [帧数]
#   探针里可用 px() / pump(n) / tap(fx,fy) / drag(fx,fy)，最后一个表达式会被打印

# ③ 死没死。全量体检
pnpm --filter @rewindom/useless exec tsx scripts/audit-useless.ts [标题...]

# ④ 好不好看。按计划走一段并截图，务必在亮色上也看一眼
pnpm --filter @rewindom/useless exec tsx scripts/_shot.ts <标题> <目录> "名字:帧数[:fx/fy],..."
```

探针写法：与其数颜色阈值，不如**竖着切成 24 条报平均亮度**（一眼看出东西堆在哪儿），
或者数某一列上穿过几条线。细的抗锯齿线永远打不到 `r>200` 这种阈值，
按颜色数会得出「什么都没画」的假结论。

第 ④ 步不能省：舞台底色已经透明（`transparent-thumbnails`），
浅奶油、浅蓝在亮色页上等于没有。**读者要认领的那个东西一律走 `INK(a)`**，
跟页面前景走；点缀色用压深过的琥珀 `rgba(224,150,40,a)`，亮暗两边都读得出。
